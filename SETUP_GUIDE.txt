STEP 1 — VERIFY NODE.JS IS INSTALLED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open Command Prompt (Windows) or Terminal (Mac/Linux) and run:
  node --version    → Should show v18.x.x or higher
  npm --version     → Should show 9.x.x or higher

If not installed: https://nodejs.org → Download LTS version

Also install nodemon globally:
  npm install -g nodemon

STEP 2 — SET UP MONGODB ATLAS (Free Database)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to https://cloud.mongodb.com → Sign up free (use Google)
2. Create a NEW project → Name it "HerGuardian"
3. Build a Database → Choose "Free" (M0) tier → Create
4. Wait ~2 minutes for cluster to provision
5. Click "Connect" → "Drivers" → Copy the connection string
   It looks like: mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/
6. Replace <password> with YOUR actual password
7. Add "/herguardian" at the end: ...mongodb.net/herguardian
8. NETWORK ACCESS → Add IP Address → "Allow access from anywhere" (0.0.0.0/0)
   (Important! Without this, connection will be refused)

STEP 3 — SET UP GMAIL APP PASSWORD (for Email SOS Alerts)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

IMPORTANT: Use a PERSONAL Gmail account (not institutional/college Gmail).
College Gmail accounts block App Passwords by admin policy.

1. Sign in to your personal Gmail at gmail.com
2. Go to: myaccount.google.com → Security
3. Under "How you sign in to Google" → Enable "2-Step Verification"
   (Must be ON before App Passwords work)
4. Go back to Security → Search "App passwords" in the page
   OR go to: myaccount.google.com/apppasswords
5. App name: "HerGuardian" → Click "Create"
6. Google shows a 16-character code like: abcd efgh ijkl mnop
7. Copy it WITHOUT spaces: abcdefghijklmnop
8. You'll use this in .env as GMAIL_APP_PASSWORD

STEP 4 — SET UP TWILIO (for SMS SOS Alerts)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Free trial available — no credit card needed initially.

1. Go to https://www.twilio.com → Sign up free
2. Verify your phone number during signup
3. Go to Console → Account Info:
   - Account SID: ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   - Auth Token: (click to reveal)
4. Get a free phone number: Phone Numbers → Manage → Buy a number
5. Choose any US number that supports SMS
   Your free number looks like: +1XXXXXXXXXX

IMPORTANT FREE TRIAL LIMITATION:
→ Free Twilio can ONLY send SMS to "Verified Caller IDs"
→ To test: Console → Phone Numbers → Verified Caller IDs → Add numbers
→ Add your team members' phone numbers here for testing
→ For production: Upgrade to paid tier ($15 credit to start)

STEP 5 — GET ANTHROPIC API KEY (for AI Legal Chatbot + Health Insights)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to https://console.anthropic.com → Sign up
2. API Keys → Create Key → Copy it
3. Format: sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
4. Add $5 credit to enable API calls (very cheap — ~$0.003 per message)
5. Paste in .env as ANTHROPIC_API_KEY

NOTE: Without this key, the AI Legal Chat and Smart Health Insights
tabs will show errors. All other features (SOS, health tracking, forum,
legal info, map) work WITHOUT the Anthropic key.

HTTPS SETUP (Required for Camera + Voice SOS on Mobile)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Camera (evidence capture) and Voice SOS require HTTPS on mobile devices.
For local dev with HTTPS:

1. In frontend/package.json, the "dev:https" script is already set up
2. In frontend/vite.config.js, uncomment the basicSsl lines:
   - Line: import basicSsl from '@vitejs/plugin-basic-ssl';
   - Line: basicSsl(),  in plugins array
3. Run: npm run dev:https
4. Browser will warn about self-signed certificate → Click "Advanced" → "Proceed"
5. Now camera and voice SOS work on mobile too

COMMON ERRORS AND FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "MongoDB Connection Error" or "ECONNREFUSED"
→ Check MONGO_URI spelling in .env
→ MongoDB Atlas → Network Access → Add 0.0.0.0/0
→ Check username/password in the URI (no special chars unescaped)

❌ "Cannot find module 'axios'"
→ You forgot npm install in the backend folder
→ Run: npm install (in backend directory)

❌ SMS not sending
→ Twilio free trial: add recipients as Verified Caller IDs first
→ Check TWILIO_ACCOUNT_SID and TWILIO_AUTH_TOKEN are correct
→ Check TWILIO_PHONE_NUMBER includes country code (+1XXXXXXXXXX)

❌ Email not sending
→ Must use PERSONAL Gmail (not college/institutional Gmail)
→ GMAIL_APP_PASSWORD must be 16 chars with NO spaces
→ 2-Step Verification must be enabled on that Gmail account
→ Check GMAIL_USER is the full email (yourname@gmail.com)

❌ AI chatbot returns "temporarily unavailable"
→ Check ANTHROPIC_API_KEY is set correctly in .env
→ Make sure you have API credits at console.anthropic.com
→ Restart the backend after adding the key (Ctrl+C, then npm run dev)

❌ "Port 5000 already in use"
→ Change PORT=5001 in .env
→ Also update vite.config.js proxy target to http://localhost:5001

❌ CORS error in browser console
→ Make sure backend is running on port 5000
→ CLIENT_URL=http://localhost:5173 in .env
→ Restart backend after .env changes

❌ Camera/Voice SOS not working
→ These require HTTPS on most mobile browsers
→ On desktop Chrome/Edge they work over HTTP (localhost only)
→ For mobile: use the dev:https setup described above

❌ "Voice SOS not supported in this browser"
→ SpeechRecognition is Chrome/Edge only — not available on Firefox
→ Standard tap-to-SOS works on all browsers

  GET  /api/health/cycle           → Get cycles 🔒
  POST /api/health/mood            → Log mood 🔒
  GET  /api/health/mood            → Get mood history 🔒

LEGAL:
  GET  /api/legal                  → Get legal articles
  GET  /api/legal/helplines        → Get helplines

FORUM:
  GET  /api/forum                  → Get approved posts
  POST /api/forum                  → Create post 🔒
  POST /api/forum/:id/like         → Like/unlike post 🔒
  POST /api/forum/:id/reply        → Reply to post 🔒

MAP:
  GET  /api/map/zones              → Get nearby zones (?lat=&lng=)
  POST /api/map/report             → Report zone 🔒

AI (NEW):
  POST /api/ai/chat                → Legal AI chatbot 🔒
  POST /api/ai/health-insights     → Smart health insights 🔒

🔒 = Requires Authorization: Bearer <token> header

FRONTEND → Vercel (free)
  1. Push code to GitHub
  2. Go to vercel.com → Import Repository → Select frontend folder
  3. Framework: Vite → Deploy
  4. Add environment variable: VITE_API_URL=https://your-backend.onrender.com

BACKEND → Render.com (free)
  1. Go to render.com → New Web Service → Connect GitHub
  2. Root Directory: herguardian_updated/backend
  3. Build Command: npm install
  4. Start Command: node server.js
  5. Add ALL .env variables in the Environment tab

After deploying:
  → Update CLIENT_URL in backend env to your Vercel URL
  → Update Twilio webhook URLs if needed
  → Test all 10 features end-to-end on the live URL
  → Upgrade Twilio to paid tier for SMS to all numbers
